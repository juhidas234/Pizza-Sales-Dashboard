# Pizza-Sales-Dashboard
Pizza Sales Analysis & Business Insights | Power BI

Tools: SQl Server ,Power BI, DAX, Excel, Data Visualization

Developed an interactive dashboard to monitor key performance indicators such as revenue, order volume, and customer behavior across different time periods, product categories, and pizza sizes.

- Key Features
~KPI tracking: Total Revenue (~$817K), Total Orders, Average Order Value
~Sales trend analysis (daily & monthly)
~Top & bottom product performance analysis
~Category and size-wise sales distribution
~Interactive filters and slicers for dynamic analysis

- Key Insights
~Top-performing pizzas contribute a significant portion of total revenue
~Peak sales occur during weekends (Friday & Saturday evenings)
~Seasonal trends show higher demand in July and January
~Classic category and Large-size pizzas dominate overall sales

- Business Impact
~Enables data-driven decision-making
~Helps optimize inventory and staffing
~Supports targeted marketing and promotions
~Identifies opportunities to improve low-performing products
